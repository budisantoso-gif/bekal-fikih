# Bekal Fikih

Teman belajar fikih berbasis web seluler (satu berkas HTML, bisa dipasang ke layar utama dan dibuka tanpa sinyal setelah sekali dibuka online).

- `tools/make_assets.py` — ikon, font lokal, QR

Isi disusun dari rekaman kajian dan syarah al-Bayan, belum direview ustadz. Font: Amiri, Noto Naskh Arabic, Plus Jakarta Sans (SIL OFL 1.1; lihat `fonts/LICENSES.txt`).
